# Transaction Analytics Project

## Описание

Проект анализирует банковские транзакции из Excel-файла и формирует отчёты:

- расходы по картам
- топ категорий трат
- поиск транзакций
- приветствие по времени суток
- курсы валют
- цены акций
- отчёт по тратам за 3 месяца

---

## Структура проекта
src/
1. views.py # Основные функции + считывание API + общий JSON
2. services.py # поиск транзакций по ключевому слову
3. reports.py # отчёты и логирование

## Установка (poetry)

```poetry install```

## Создание и настройка API ключей
- Создать файл .env по форме файла .env.example
- Получить и вписать API_KEY (alphaavantage) и API_KEY_STOCK (twelvedata)
